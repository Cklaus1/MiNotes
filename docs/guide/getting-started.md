# Getting started

## Pages and blocks

A **page** is made of **blocks**. Every paragraph, bullet or heading is a block, and blocks can sit inside other blocks.

- Click in a block and type. **Enter** starts a new block below.
- **Tab** indents the block under the one above it. **Shift+Tab** moves it back out.
- Press **Esc** to stop editing. Drag the handle on the left of a block to move it.
- Click the small arrow next to a block that has children to fold or unfold it.
- Type `/` to insert a heading, to-do, table, callout, code block, whiteboard and more.
- Select text for a small toolbar (bold, italic, code, highlight). **Ctrl+B**, **Ctrl+I** and **Ctrl+E** work too.
- **Ctrl+Enter** turns a line into a to-do and cycles it TODO, DOING, DONE.
- **Ctrl+Z** undoes. Pages you delete go to Trash first.

## Links

- Type `[[` and start typing a page name to link to it. Pick one from the list.
- Open any page and look for **Backlinks**: every page that links here, plus mentions that are not linked yet.
- Type `((` to refer to a single block. The text of that block shows in your page and stays up to date.
- Add `#tags` anywhere in a block.

## The journal

**Ctrl+J** opens today's journal page, created for you. **Alt+Up** and **Alt+Down** step to the previous and next day. You can link to a day from any page, for example `[[Journal/2026-11-17]]`, or type a date in words and choose the suggestion.

## Projects, pins and notebooks

- Projects are folders for pages. Create them in the sidebar and drag pages in.
- Right-click a page to pin it. **Ctrl+1** to **Ctrl+7** open your first seven pinned pages.
- A **notebook** is a whole separate collection of notes (work, personal, a private one). Switch from the top of the sidebar.

## Tabs

- **Ctrl+T** opens a new tab. A normal click on a link changes the current tab.
- **Ctrl+click** or middle-click opens a link in a background tab. **Ctrl+Shift+click** opens it and switches to it.
- **Ctrl+Tab** and **Ctrl+Shift+Tab** move between tabs. **Alt+1** to **Alt+8** jump to a tab. **Ctrl+W** closes one.
- **Ctrl+[** and **Ctrl+]** go back and forward inside a tab.

## Search and commands

**Ctrl+K** opens search. Type to find pages, blocks and journal days; press **Tab** to narrow to one kind. Type `>` to run a command (settings, new page, lock notebook, and so on). **Ctrl+Enter** on a result opens it in a new tab.

## Other views

**Ctrl+G** shows the graph of your links. **Ctrl+M** a mind map. **Ctrl+Shift+K** a kanban board. **Ctrl+Shift+W** starts a new whiteboard. The **TODO** badge in the sidebar opens a list of all your open tasks.

## Keyboard shortcuts

Press **Ctrl+/** in the app for the full list. The most useful ones:

| Shortcut | What it does |
|---|---|
| Ctrl+K | Search and commands |
| Ctrl+J | Today's journal |
| Ctrl+N | New page |
| Ctrl+T / Ctrl+W | New tab / close tab |
| Ctrl+Tab | Next tab |
| Ctrl+[ / Ctrl+] | Back / forward |
| Ctrl+1 ... Ctrl+7 | Open pinned page 1 to 7 |
| Ctrl+G | Graph |
| Ctrl+M | Mind map |
| Ctrl+Shift+K | Kanban |
| Ctrl+Shift+W | New whiteboard |
| Ctrl+Shift+I | Import notes |
| Ctrl+Shift+T | Light / dark theme |
| Ctrl+Shift+L | Lock an encrypted notebook |
| Ctrl+Shift+\ | Show or hide the sidebar |
| Ctrl+, | Settings |
| Ctrl+/ | List of shortcuts |
| Enter / Tab / Shift+Tab | New block / indent / outdent |
| Ctrl+Enter | Cycle TODO, DOING, DONE |
| Alt+Right / Alt+Left | Zoom into a block / back out |
| Ctrl+Z / Ctrl+Shift+Z | Undo / redo |
| Esc | Close the open panel or menu |
