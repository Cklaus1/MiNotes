# MiNotes user guide

Short, task-based pages for people who use MiNotes.

- [Install](install.md): Windows and Linux, uninstall, where your notes are stored
- [Getting started](getting-started.md): pages, blocks, links, the journal, tabs, search and shortcuts
- [Import](import.md): bring in notes from Evernote, Obsidian or a folder of markdown files
- [Sync](sync.md): keep two or more devices up to date through git
- [Encryption](encryption.md): lock a notebook with a passphrase
- [FAQ](faq.md): common questions

Something missing or wrong? Open an [issue](https://github.com/Cklaus1/MiNotes/issues/new/choose) or ask in [Discussions](https://github.com/Cklaus1/MiNotes/discussions).
